# AON / CoCubes Assessment Interface Clone

An online assessment interface replica featuring section navigation, dynamic timer, question palette, fullscreen exam mode, and question flow.

## Features
- Fullscreen examination flow & proctoring overlays
- Timed assessment with countdown
- Dynamic question palette & sections (Technical, Subjective, etc.)
- Responsive candidate dashboard interface

## Getting Started
Simply open `index.html` in any modern web browser or run with a local live server:
```bash
npm start
```
